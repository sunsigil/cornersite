FAQ

Can I contribute to the current Cornerlight issue?

Yes! Please fill out the page request form linked above. Understand that if you submit a page request, you will be expected to submit your pages by the volume's release date. As such, you should not try to get pages in a volume that is a week or less away from release unless you already have the work done.

How should I submit my pages?

Please upload them via the submission form linked above. One file per page is ideal.

What file format is best for submissions?

Anything that is commonly accepted by software that normal people use. PDF is great, PNG is great, JPG is great. Nothing too weird please.
